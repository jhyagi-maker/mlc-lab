## Project notes

Lab website maintained by a non-developer. Keep all editable content in `src/data/` (YAML + Markdown) so they never need to touch `.astro` files; `README.md` is their Korean editing guide — update it when the data format changes.

- `src/data/lab.yaml`, `members.yaml`, `publications.yaml`, `projects.yaml` are loaded as collections in `src/content.config.ts` (list items get auto `id`/`order`; schema errors are in Korean). News is `src/data/news/*.md`.
- Use `url()` from `src/lib/site.ts` for every internal link/asset: `base` is derived from `GITHUB_REPOSITORY` for GitHub Pages project sites.
- Deploy: `.github/workflows/deploy.yml` (withastro/action) on push to `main`.
- `/autolab` ("실험실 연구진행") shows results from the sibling `../mlc-auto-lab` harness. `src/data/autolab/**` and `src/data/autolab-meta.json` are generated by `npm run autolab` (`scripts/sync-autolab.mjs`) — never hand-edit them.
- News entries may be folders (`<slug>/index.md` + images) with a `slug:` frontmatter key.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
